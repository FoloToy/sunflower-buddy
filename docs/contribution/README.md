# Contribution

This directory defines the collaboration contract for humans and coding agents.

- [Commit and PR rules](commit-and-pr.md)
- [Documentation conventions](doc-conventions.md)

Reviews must distinguish source/build checks from device evidence and must not
publish unredacted Wi-Fi, Bluetooth, modem, or device identifiers from logs.

Before changing code, read `AGENTS.md` and the task-specific hardware guide.
Keep the repository focused on the Sunflower Buddy V1.4 board reference and preserve
unrelated work in an existing checkout.
