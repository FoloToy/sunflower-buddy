# 贡献规范

本目录定义人类开发者与 AI 编程助手共同遵守的协作约定。

- [提交与 PR 规范](commit-and-pr.zh_CN.md)
- [文档规范](doc-conventions.zh_CN.md)

Review 必须区分源码/构建检查与真机证据，不得发布日志中未脱敏的 Wi-Fi、蓝牙、模组
或设备标识。

修改代码前先阅读 `AGENTS.zh_CN.md` 和任务对应的硬件指南。仓库只维护 Sunflower Buddy V1.4
板级参考实现，并保留已有 checkout 中与当前任务无关的修改。
