# 代码规范

## 位置与命名

- 跟随相邻 C/C++ 文件，使用四空格缩进。公开板级 API 使用 `bsp_`，文件内状态使用
  `s_`，硬件常量使用 `BSP_*`。
- 可复用的硬件资源所有权和时序放在 `components/bsp`；Demo 状态与用户交互放在
  `main`。Wi-Fi/BLUFI 配网不是板级专用外设 API，保留在 `main/demo_blufi.*`。
- 引脚、总线、地址、时钟和已验证电气参数只能定义在
  `components/bsp/include/bsp_pins.h`。
- 本硬件参考仓库不得加入产品服务、凭据、OTA、云协议或产品状态机。

## 资源所有权与并发

- 只通过 `bsp_i2c_init()` 初始化一次 I²C，并复用 `bsp_i2c_bus()`。
- 按键与 GX8002 回调运行在组件任务中，PMU 与 RTC 回调运行在 BSP 工作任务中；均应
  快速返回。录音、播放、休眠或等待等应用工作应通过队列交给应用任务。
- Wi-Fi、IP、BLE 与定时器回调只能复制有界数据、更新原子状态或排队；扫描、NVS
  修改、重连策略和重置流程必须在配网任务执行。
- PCM 读写和灯光闪烁辅助函数会阻塞，只能在应用任务中调用，不能在 ISR 中调用。
- 缓冲区由使用它的任务持有。当前 Demo 在 PSRAM 中分配录音缓冲区，回放结束后释放。
- 检查所有 `esp_err_t`。MX6115 上游接口返回的是 FreeRTOS 队列结果，应使用 BSP
  包装接口，不能把原始 `pdPASS` 误判为 ESP-IDF 错误。
- 禁止输出 Wi-Fi 密码内容。日志可以记录有界凭据长度和数字断线原因；对外发布真机
  日志前应脱敏 SSID、BSSID、IP 和设备地址。

## 硬件规则

- GX8002 上电顺序必须为 3.3 V I/O、等待 10 ms、1.0 V Core；断电顺序相反。
- AXP2101 与 MCU 进入深睡前必须关闭 ES8311 输入和输出。
- 电机占空比范围为 0–1023。无人值守或持续动作时保留过流检测，并在真机标定阈值。
- 音量范围为 0–100；应用以 10% 步进调整，驱动不得再次隐式缩放百分比。
- 调用 `bsp_modem_uart_init()` 会把 UART0 路由到 LTE 模组，使用前必须考虑当前 console 配置。

## 测试与文档

- 修改仓库契约或纯逻辑时同步更新主机检查。
- 硬件修改必须记录真机验收；编译通过不能证明电气、声学、射频、功耗或时序正确。
- 配网修改需记录清空/已保存 Station 配置、重连、长按重置，以及至少三轮重复 BLUFI
  会话测试，并注明 App 版本。
- 英文与简体中文文档必须配对，并保持事实一致。
- 编译、主机测试、设备测试和未验证项必须分别报告。
